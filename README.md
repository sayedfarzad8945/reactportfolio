# Sayed Yahya — Portfolio (React + Tailwind CSS)

Same portfolio as the original HTML/CSS version, rebuilt with Vite, React and Tailwind CSS.

## Run it

```bash
npm install
npm run dev      # http://localhost:8080
npm run build    # production build in /dist
```

## Structure

```
src/
  assets/        portrait + project images
  components/    Navbar, Hero, About, Skills, Work, Resume, Contact, Footer, Button, Kinetic
  data.js        all text content (edit your info here)
  index.css      Tailwind + dark/light theme variables
  App.jsx
  main.jsx
```
